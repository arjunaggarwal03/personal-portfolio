Recently, I've been working on a public API and Python SDK at Lightfield. Our
own agent uses both.

Making an internal operation public forces decisions that were easy to leave
implicit. What is a task? Which fields can a developer depend on? What happens
when an agent action needs approval or fails halfway through?

Writing the docs has been a good test. If an operation takes a paragraph to
explain, I probably haven't found the right boundary yet.
